# 运行预筛加速测试

修改预筛的规则转换、原生库接口、包格式或加载流程后，可以运行专项测试。下面的命令用于 Linux，需安装 Python 3.10 或更高版本以及 uv。

## 运行源码测试

从仓库根目录进入 `AgentMoss/` 并创建测试环境。测试使用项目依赖和 pytest。

```bash
cd AgentMoss
uv venv --python 3.12 .venv-prefilter
uv pip install --python .venv-prefilter/bin/python -e . pytest
AGENT_MOSS_ROOT="$PWD" AGENT_MOSS_DISABLE_LLM=1 .venv-prefilter/bin/python -m pytest \
  tests/test_prefilter_*.py tests/test_regex_subset_parser.py -q
```

上述测试覆盖规则转换、Python 回退、磁盘包完整性和热更新。需要真实动态库的用例会在缺少库时跳过。在 x86_64 上，将 `AGENT_MOSS_TEST_HS_LIB` 设为完整 Hyperscan 库的绝对路径，再运行同一条 pytest 命令。部分用例约定使用 x86_64 的 Hyperscan。在鲲鹏上验证 Ultrascan 的加载和扫描时，使用下面的安装包检查。[动态库准备说明](../docs/预筛加速使用说明.md#准备动态库)

## 验证独立安装包

需要同一后端、同一数字版本的完整库 `libhs.so` 和运行库 `libhs_runtime.so`。在 `AgentMoss/` 组件目录中运行。把两个 `/path/to/` 路径替换为本机库的绝对路径，x86_64 上将 `--backend` 改为 `hyperscan`。

```bash
component_dir="$PWD"
work_dir=$(mktemp -d)
uv build --wheel --out-dir "$work_dir/dist" .
uv venv --python 3.12 "$work_dir/venv"
uv pip install --python "$work_dir/venv/bin/python" "$work_dir"/dist/*.whl
cd "$work_dir"
"$work_dir/venv/bin/python" "$component_dir/tests/verify_prefilter_wheel.py" \
  --install-root "$work_dir/venv" \
  --compile-lib /path/to/libhs.so.5.8.0 \
  --runtime-lib /path/to/libhs_runtime.so.5.8.0 \
  --backend ultrascan --expect-runtime-only
```

脚本从已安装的 wheel 导入代码，先编译和加载规则包，再更新规则并检查在途扫描是否仍能使用旧包。返回 `hot_update: "passed"` 表示这些检查通过。

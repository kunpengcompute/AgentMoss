# 预筛加速测试说明

## 覆盖内容

测试覆盖默认关闭、规则转换、真实原生库调用、规则对应、异常回退、自动生成、热更新、并发扫描、fork 和资源清理。规则差分和小字符集合穷举检查 Python 原规则匹配时不会被预筛排除。

自动更新重点验证：

- 规则读取不写回配置、不污染业务缓存；读取中发生变化时放弃本次快照。
- 启动时实际读入的内容与来源标识一致；规则修改后又回滚，也不会让旧进程错误取得发布资格。
- 规则稳定后生成，相同内容不重复生成；多个进程竞争时只生成一次，同一失败输入共用重试间隔。
- 更新失败保留旧内存数据库；原生库在某个进程中分配内存失败，不破坏完整的共享磁盘包。
- 在 building、各包文件写到一半、试加载后和 ready 前后强制结束生成进程，重新加载只能接受完整包，否则使用 Python 后重建。
- 停止时不无限等待提交，也不提前释放仍在写文件的锁；fork 后子进程不解锁父进程。

## 验证结果

| 环境与范围 | 通过 | 跳过 | 失败 |
|---|---:|---:|---:|
| x86，真实 Hyperscan 5.4.2，预筛及解析器专项 | 195 | 6 | 0 |
| ARM，真实 Ultrascan 5.8.0，同一专项 | 195 | 6 | 0 |
| x86，产品全量 | 3317 | 144 | 4 |
| x86，同环境 main 全量 | 3122 | 138 | 相同 4 项 |
| ARM，产品全量 | 3313 | 144 | 8 |
| ARM，同环境 main 全量 | 3118 | 138 | 相同 8 项 |

x86 与 ARM 均完成同包跨 Python 3.10～3.14 加载检查。x86 独立安装的 wheel 已通过纯运行库加载、热更新及在途旧数据库继续扫描检查。

两种环境共有的四项失败涉及通配删除判定及 Python/PHP 内联删除的风险类型。ARM 另有四项 `read_before_write` 相关用例失败，同环境 main 结果一致。未改写这些业务用例的预期，本次修改没有新增全量回归失败。

专项的六项跳过是当前 Python 不接受对应原始正则语法。全量跳过还包括未配置 LLM、缺少回放数据等条件。有限测试不等同于任意规则、任意生产环境的正确性证明；强制结束进程也不等同于真实掉电测试。

## 执行入口

功能测试位于 `tests/test_prefilter_*.py`、`tests/test_regex_subset_parser.py`。设置 `AGENT_MOSS_TEST_HS_LIB` 指向完整原生库后运行。ARM 验证将测试中的后端名称和不兼容架构断言调整为当前机器，产品代码保持一致。

测试应在隔离环境中执行，避免接触宿主运行时配置。独立安装检查入口为 `tests/verify_prefilter_wheel.py`。网络共享文件系统、真实掉电和长期生产负载不在本轮验证范围内。
